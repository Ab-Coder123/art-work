# Gemini Brief: Replace Website Copy Without Adding Clutter

## Goal

Update the existing Art Work website copy so it clearly represents an event planning, production and brand-experience company. Keep the current visual identity and page structure. Make the content shorter and easier to scan; do not add new sections or redesign the site.

Before editing, inspect the repository `AGENTS.md` files and the current content source used at runtime. Review the home page, Services matrix, Why Us page, gallery and contact form. Preserve the existing content model and make changes in the actual source of truth so the public site and dashboard do not drift apart.

## Use These Skills

- Use `web-design-guidelines` to check content hierarchy, readability, accessibility and visual density. If the skill is unavailable, apply those principles directly.
- This is a copy update, so do not use a visual redesign workflow or introduce new UI patterns unless a small change is necessary to remove clutter.

## Copy Rules

- Keep the hero headline to two short lines and its paragraph to one or two short sentences.
- Use one eyebrow/span per section. Avoid stacked stickers, duplicate claims and decorative labels that repeat the same message.
- Keep card titles to about 3-6 words and descriptions to one short sentence (about 12 words maximum).
- Do not add statistics, client names, locations, testimonials, response-time promises, technical specifications or guarantees unless they are verified in the project and approved for publication.
- Remove unsupported claims already in the site, including performance marketing/ROI claims, audience and project counts, cue-accuracy percentages, 72-hour/24-hour promises, arena capacities and invented case-study details.
- Keep existing components, navigation, forms, API behavior and styling intact. Edit copy only wherever possible. Do not start, stop or restart any development server.

## Replace the Existing Copy

- `CREATIVE IDEAS.` / `REAL IMPACT.`

- **Eyebrow:** `EVENTS, EXHIBITIONS & BRAND EXPERIENCES`
- **Headline, line 1:** `WE TURN IDEAS`
- **Headline, line 2:** `INTO LIVE EXPERIENCES.`
- **Paragraph:** `From the initial concept to the final execution, we create memorable experiences that bring brands to life.`
- **Primary CTA:** `VIEW OUR PROJECTS`

Remove the hero metric tiles unless verified, or replace them with one concise line. Do not invent replacement numbers.

Keep this teaser brief. Do not repeat the full service list here.
